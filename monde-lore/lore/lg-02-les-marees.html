Les marées

Ce que chacun sait monte comme une marée. Chaque fil est une phrase du script ; il se lève à la séquence où quelqu’un l’apprend. Le Maître est plein avant le premier plan. Toi, à la dernière image.

Fais défiler : le film passe, de la première à la treizième séquence.

    Ce qui reste ouvert

    Ce que sait le Maître avant le film n’est presque jamais dit : on le déduit de ce qu’il fait. C’est lui qui écrit les phrases, c’est lui qui pose les objets.

    Delvaux n’apprend plus rien après la séquence 5. Le script ne lui donne pas de scène où il comprend.

    Comment lire le trait

    • plein : le script le dit
    • pointillé ambre : on le déduit
    • un rond vide : ça manque
    • orange : ce qu’on suit
