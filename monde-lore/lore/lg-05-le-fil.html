Le fil

Dix-sept lettres écrites dans un livre, avant 1995. Elles traversent tout le film sans rien dire, passent sous les pages, remontent quatre fois. Un seul fil, de la main inconnue au dernier plan.

Fais défiler : le fil avance dans le script, page après page.

    Ce qui reste ouvert

    Le script le dit lui-même : « Le livre n’a jamais appartenu à son père à l’origine. Babakar Diop l’a trouvé, reçu, ou peut-être même volé. »

    Qui écrit la dédicace, et quand : la bible du monde garde la case vide. C’est le fait le plus ancien du film, et le plus vide.

    Comment lire le trait

    • plein : le script le dit
    • pointillé ambre : on le déduit
    • un rond vide : ça manque
    • orange : ce qu’on suit
