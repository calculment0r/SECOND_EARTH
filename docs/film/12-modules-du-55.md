# Modules du 55

Neuf modules, 27 minutes. Chacun s'insère dans une charnière du 25 (onglet Architecture), porte un enjeu propre, et paie un crochet déjà présent dans le court. La colonne Expo dit ce que la salle immersive ou l'expo classique reprend tel quel. Intégré au round 17 (16/11/2026) : M9 est placé après M4 ; M8 s'arrête avant le cri, Seed garde le caillou blanc, et le retour repasse devant le totem ; M1 montre les six souvenirs du plan 7-11.

| Module | S'insère à | Durée | Contenu | Enjeu propre | Expo |

| **M1 · Elena, 2045** | E1, prologue | 3:00 | La Terre qui mue : giga-feux, digues, serres. Les six souvenirs que Seed reverra au plan 7-11, vus ici du côté d'Elena (S7, validé round 17) : Elena enfant devant les fourmis ; le diplôme, les jumeaux ; le laboratoire ; la forêt en flammes ; sa main qui écrit PERSEPHORA ; la signature (don d'ADN, don de conscience). Trois modules (M2, M7, M9) sont entièrement sans Seed ; deux (M4, M5) la montrent endormie ou de loin. Ces cinq-là sont à construire dans Unreal avec BoraBora, pour la salle immersive d'abord ; le 55 les rend depuis le moteur. Les quatre autres (M1, M3, M6, M8) suivent la même fabrication que les séquences-cœur.
