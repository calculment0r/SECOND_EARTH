# Propositions

Ce que le docx et la Bible n'ont pas encore, rangé par nature. Round 13 tranché le 27/09 : S1 quatre mots (oui), S3 le flash (non : c'est le sourire de Seed, pas la charte), S5 le caillou dans l'alvéole (oui), S8 la ligne des 11,4 ans (oui), S11 l'épigraphe (la phrase du docx n'est pas gardée, à remplacer), L1 Mars et Titan (oui, comme collecteurs), E2 le cri comme seul mot de l'expo (non), P2 Unreal pour les modules (oui), P5 le format (les deux).
