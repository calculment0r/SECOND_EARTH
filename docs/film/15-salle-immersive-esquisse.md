# Salle immersive, esquisse

Une proposition de structure pour la salle développée avec BoraBora, à partir des points validés (narration sans Seed, visiteur chef de mission, contemplatif avec un peu d'interaction, jamais scolaire) et des modules du 55. Rien n'est décidé ; c'est ce que les documents existants permettent déjà de construire.

## Le principe

Le visiteur est PERSEPHORA, ou son chef de mission : il voit ce que les Robs envoient. Il ne voit jamais Seed ; il voit ses traces (une empreinte, le totem, le caillou dans l'alvéole) et il entend le journal de Rob1. La salle dure 12 à 15 minutes et se termine sur le rapport final de Rob1 puis le carton (A10 tranché : pas de cri Korê en signature).

## Six temps

| Temps | Durée | Ce qu'on voit | Ce qu'on fait | Source déjà écrite |
| --- | --- | --- | --- | --- |
| 1 · L'orbite | 1:30 | La planète entière, les codes de mission, les quatre signatures qui s'allument sur le continent A ; les capsules qui descendent | Le visiteur choisit le site : les autres continents répondent « NON » avec leur raison ; A répond « OUI » | Carte de Korê (vue Planète), onglet Continents et océans |
| 2 · Phase 1 | 4:00 | Les Robs explorent, point de vue par point de vue : la grotte à guano, la forêt bioluminescente, la fosse ; les drones qui reviennent | Contemplatif ; le journal de Rob1 tient le fil | Module M2 ; Bestiaire ; Flore |
| 3 · Le sinkhole | 1:00 | Le sol qui cède, le mât-relais qui bascule ; le silence ; les balises des robopods qui clignotent seules | Rien : la salle s'éteint presque | Séquencier, Acte I |
| 4 · La lumière comme langue | 3:00 | La caverne des plantes-chant, puis la forêt bioluminescente en saison noire | Le visiteur éclaire ; les plantes répondent par pulsations, avec le code de Rob4 (proposition E3) | Modules M5 ; Bestiaire TR-05 ; Lumière et couleurs |
| 5 · Il y a 60 millions d'années | 2:00 | Les Titans vivants, l'étoile de passage, la pluie de comètes, le squelette qui finit dans la voûte | Contemplatif | Module M9 ; onglet Les Titans |
| 6 · Korê | 2:00 | La course volcanique vue du tank, la mer d'arsenic, Rob4 qui remonte ; puis les lacs pourpres, la colonie qui décolle | Le rapport final de Rob1, NON VIABLE ; le carton final | Modules M7, M8 ; Cartels |

## Ce que ça implique

- Les temps 2, 4, 5 et 6 sont les modules M2, M5, M9, M7 et M8 du 55 : une seule construction dans Unreal (QCM A06).
- Le journal de Rob1 est écrit une fois (proposition P3) ; la salle en prend la version courte.
- La carte interactive est déjà la vue de l'orbite du temps 1.
- L'expo classique par biome, avec ses cartels, se visite après la salle : on y retrouve ce qu'on vient de voir, expliqué.
